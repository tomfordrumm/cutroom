# Образец раскадровки: плохо и хорошо

Один и тот же фрагмент речи в двух раскадровках. Тема и картинки здесь ради примера: не переноси их в свой ролик, переноси способ думать.

Бриф: хук в камеру, дальше моушен на весь кадр.

> «Все фото у вас в одном телефоне? Это как хранить семейный альбом в коробке у двери: один потоп — и ничего нет. Телефон тонет, теряется, разбивается. А исправить это — две минуты: зайдите в настройки, включите резервную копию, и всё уедет в облако само. Потеряете телефон — фото останутся».

## Плохо: одна рамка, меняется содержимое

`thread`: «экран телефона с галереей».

| Сцена | Что на экране | Длина |
|---|---|---|
| s1 | Телефон по центру, в нём галерея фото | 6 с |
| s2 | Тот же телефон, внутри галереи иконка коробки | 7 с |
| s3 | Тот же телефон, внутри иконки «вода», «потеря», «трещина» | 5 с |
| s4 | Тот же телефон, внутри экран настроек, курсор включает переключатель | 9 с |
| s5 | Тот же телефон, внутри галочка «Фото в облаке» | 5 с |

Что не так:

- Все пять кадров на листе — один и тот же телефон в одном месте. Это слайд-шоу внутри рамки.
- Сравнение с коробкой стало иконкой в галерее. Мира сравнения нет, зритель его не увидел.
- «Тонет, теряется, разбивается» — три иконки-слова, а не события.
- В сценах по 6–9 с одно состояние. Между событиями проходит по 4–5 с.

## Хорошо: предмет живёт, сравнение получает свой мир

`thread`: «телефон с фотографиями; в мире сравнения те же фото лежат в картонной коробке. Связка — одна фотография, которая проходит через оба мира».

| Сцена | `device` | Что на экране | `carry` | Длина |
|---|---|---|---|---|
| s1 | `thing` | Крупно телефон на бо́льшую часть кадра, фото листаются. Камера наезжает на одно фото — семья на пикнике | камера влетает в это фото (`zoomThrough`) | 2,5 с |
| s2 | `metaphor` | Фото во весь кадр отъезжает и оказывается одним из снимков в картонной коробке у двери прихожей. Коробка стоит на полу, общий план | коробка остаётся | 3 с |
| s3 | `metaphor` | По полу ползёт вода, доходит до коробки, фото темнеют и коробятся. Удар: коробка оседает | с мокрого фото сцена сворачивается в точку (`iris`, `reverse`) | 2 с |
| s4 | `example` | Снова телефон, но маленький и сбоку: три быстрых удара — телефон падает в воду, остаётся на скамейке, по экрану бежит трещина | телефон вырастает на весь кадр (`morph`) | 3 с |
| s5 | `thing` | Экран настроек, курсор нажимает «Резервная копия», переключатель щёлкает | переключатель остаётся, из него вылетают фото | 2,5 с |
| s6 | `thing` | Фото из галереи одно за другим улетают вверх в облако, счётчик «в облаке» растёт | облако остаётся | 3 с |
| s7 | `contrast` | Телефон исчезает с трещиной, а облако открывается, и в нём то же фото с пикником | — | 2,5 с |

Почему это работает:

- Сквозной образ — телефон, но он каждый раз в новом месте и масштабе: крупно, сбоку, на весь кадр, исчезает.
- Сравнение — отдельный мир во весь кадр: место (прихожая), предмет (коробка), действие (вода). Связка — фото с пикником: зритель узнаёт его в коробке и в облаке.
- Каждые 1,5–3 с новое событие, сцены по 2–3 с.
- Каждый стык — превращение: камера влетает, сцена сворачивается, предмет вырастает.

## Как это устроено в одном компоненте

Один компонент, этап — в `props.stage`, по элементу `graphics.json` на сцену. Переход живёт в начале следующего этапа: его первые кадры рисуют конец прошлого этапа, и из него вырастает новый. Тогда `gfx review` видит на стыке общий кадр.

```tsx
import React from "react"
import { AbsoluteFill, useCurrentFrame, useVideoConfig } from "remotion"
import { Illustration, morph, rectStyle, iris, useLayout, type OverlayProps, type Rect } from "cutroom"

export default function Photos({ props, theme, u, width, height }: OverlayProps<{ stage: string }>) {
  const frame = useCurrentFrame()
  const { fps } = useVideoConfig()
  const { safe } = useLayout()
  // Где телефон на каждом этапе: крупно, сбоку, на весь кадр.
  const big: Rect = { x: safe.left, y: safe.top, w: width - safe.left - safe.right, h: height - safe.top - safe.bottom, r: 60 * u }
  const side: Rect = { x: safe.left, y: height * 0.35, w: 300 * u, h: 600 * u, r: 36 * u }

  if (props.stage === "phone-back") {
    // Начало этапа: телефон ещё сбоку, как в конце прошлого, и за 0,6 с вырастает.
    const rect = morph(frame, side, big, 0, Math.round(0.6 * fps))
    return <AbsoluteFill style={{ background: theme.background }}><div style={rectStyle(rect)}>…</div></AbsoluteFill>
  }
  if (props.stage === "flood-out") {
    // Мир сравнения сворачивается в точку на мокром фото, под ним уже следующий кадр.
    return <AbsoluteFill style={{ background: theme.background }}>
      <AbsoluteFill>…телефон сбоку…</AbsoluteFill>
      <AbsoluteFill style={iris(frame, width * 0.5, height * 0.6, { width, height }, 0, 10, { reverse: true })}>
        <Illustration id="…" size={700} />
      </AbsoluteFill>
    </AbsoluteFill>
  }
  // …остальные этапы
  return null
}
```

Персонажей и предметы мира сравнения бери из `illustrations.md` или генерируй (`guide/images.md`), не рисуй фигурами.
