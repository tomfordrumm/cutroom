# Движения и переходы

Справочник к библиотеке движений модуля `cutroom`. Лист со всеми движениями (строка на движение, шесть кадров): `cutroom gfx moves` → `frames/moves-sheet.jpg`. Открой его и выбирай по картинке.

```tsx
import { useCurrentFrame, useVideoConfig } from "remotion"
import { moves, ease, springs, useTheme } from "cutroom"

const frame = useCurrentFrame()            // кадры от начала элемента
<div style={moves.rise(frame, { delay: 6, u })}>…</div>
```

Все функции чистые: результат зависит только от кадра. Размеры в пикселях при 1080, передавай `u`, где он есть в параметрах.

## Кривые и пружины

| | Когда |
|---|---|
| `ease.snap` | прилёт, приземление, удар на акценте: быстро доходит и мягко садится |
| `ease.out` | обычный вход текста и карточек |
| `ease.glide` | камера, перенос между сценами, спокойное перемещение |
| `ease.whip` | рывок камеры к новой цели |
| `ease.back` | мелкий предмет с лёгким перелётом |
| `ease.in` | уход |
| `springs.soft` / `snappy` / `bouncy` / `heavy` | конфиги для `spring()`: панели / кнопки и сообщения / наклейки и иконки / крупные предметы и камера |

Одно и то же сглаживание на всём подряд делает ролик ватным. Резкие прилёты (`snap`) рядом с плавными переносами (`glide`) дают ритм.

## Вход и выход

- `rise(frame, { delay, duration, distance, u })` — проявление с подъёмом. По умолчанию для текста и карточек.
- `popIn(frame, { delay, fps, from })` — выскакивает с пружиной. Иконки, наклейки, число.
- `maskRise(frame, { delay, duration })` — строка выезжает из-под невидимого края; оберни в блок с `overflow: hidden`.
- `wordRise(text, frame, { delay, every, u })` → `[{ word, style }]` — слова по одному. Только для короткой ключевой фразы.
- `slideIn(frame, { from: "left" | "right" | "top" | "bottom", distance, u })` — въезд сбоку.
- `exit(frame, length, { duration, u })` — уход в последние кадры элемента; перемножь `opacity` со входом.

## Текст, который происходит

- `typeOn(text, frame, start, end)` — набранная к кадру часть текста. Паузы на пробелах и знаках, как у живой руки. Каретка: `caretOn(frame, typing)`.
- `countUp(frame, from, to, start, end, { decimals })` — число набегает до значения.
- `sweep(frame, start, duration)` → 0–1 — маркер проходит по слову (`transform: scaleX(...)`, `transformOrigin: left`).

## Контакт: одно вызывает другое

- `press(frame, at)` → масштаб — кнопка проседает в момент `at` и возвращается.
- `cursorPath(frame, [{ x, y, at, click }])` → `{ x, y, press }` — курсор едет по точкам и кликает. Отдай в `<Cursor>` и в `press` кнопки, по которой кликнули: зритель должен видеть причину.
- `shake(frame, at, { amplitude, duration, u })` → px — короткая затухающая тряска: ошибка, отказ.
- `squash(frame, at, { amount })` → `{ scaleX, scaleY }` — предмет приземлился (`transformOrigin` — низ).
- `gather(frame, i, n, start)` — элементы слетаются на свои места: сборка списка, набор из частей.
- `along(points, t)` — точка на ломаной: путь предмета.

## Перенос: следующая сцена вырастает из этой

Это то, что отличает моушен от слайдов. На каждой границе сцен решай, что её переживает.

- `morph(frame, from, to, start, end)` → `Rect` — контейнер меняет размер и место: кнопка становится окном, карточка — экраном. Содержимое следующей сцены рисуй внутри него. `rectStyle(rect)` даёт CSS.
- `zoomThrough(frame, target, { width, height }, start, end)` — камера влетает в деталь (`target` — её прямоугольник в кадре), пока та не заполнит экран. Примени стиль к сцене целиком, а следующую сцену начни как эту деталь во весь экран.
- `iris(frame, x, y, { width, height }, start, end)` — следующая сцена раскрывается кругом из предмета (`clipPath`).
- Тот же предмет меняет состояние: окно чата остаётся, меняется ответ; сумма остаётся, вокруг появляется список. Это самый частый и самый сильный перенос — держи сквозной образ в одном компоненте через несколько сцен.

Стык без переноса допустим, если между сценами снова автор в кадре, или это намеренная серия коротких ударов.

## Камера

- `camera(frame, [{ at, x, y, scale, ease }], { width, height })` — камера по ключам над «сценой» размером с кадр: `(x, y)` — точка сцены в центре кадра. Чтобы следовать за предметом, ставь ключ на пару кадров раньше него с `ease.glide`; для рывка — ключ в точке приземления с `ease.whip`. Примени стиль к контейнеру сцены.
- `drift(frame, { amplitude })` — едва заметное «дыхание» камеры в долгом удержании, не больше 4–6 px. В паузах лучше без него.

## Ритм

- Длины сцен и движений разные: удар 0,3 с рядом с удержанием 2,5 с.
- Пауза, где ничего не движется, нужна, чтобы акцент был заметен.
- `stagger(count, span)` — шаг между элементами, чтобы `count` штук уложились в `span` кадров.
- Вход 0,3–0,5 с, выход 0,2–0,3 с, между ними — время прочитать.
