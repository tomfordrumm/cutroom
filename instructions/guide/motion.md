# Движения и переходы

Полный справочник библиотеки движений модуля `cutroom`. Лист со всеми движениями (строка на движение, шесть кадров): `cutroom gfx moves` → `frames/moves-sheet.jpg`. Открой его и выбирай по картинке.

```tsx
import { useCurrentFrame, useVideoConfig } from "remotion"
import { moves, ease, springs, rise, typeOn } from "cutroom"

const frame = useCurrentFrame()            // кадры от начала элемента
<div style={moves.rise(frame, { delay: 6, u })}>…</div>
```

Каждое движение доступно и отдельным импортом (`rise`), и в объекте `moves` (`moves.rise`). Все функции чистые: результат зависит только от кадра. Время — кадры элемента (30 к/с по умолчанию, бери `fps` из `useVideoConfig()`). Размеры — пиксели при 1080, передавай `u`, где он есть в параметрах. «Стиль» ниже — объект CSS, который кладут в `style`.

## Кривые и пружины

| | Когда |
|---|---|
| `ease.snap` | прилёт, приземление, удар на акценте: быстро доходит и мягко садится |
| `ease.out` | обычный вход текста и карточек |
| `ease.glide` | камера, перенос между сценами, спокойное перемещение |
| `ease.whip` | рывок камеры к новой цели |
| `ease.back` | мелкий предмет с лёгким перелётом |
| `ease.in` | уход |
| `springs.soft` / `snappy` / `bouncy` / `heavy` | конфиги для `spring({ frame, fps, config })` из `remotion`: панели / кнопки и сообщения / наклейки и иконки / крупные предметы и камера |

Кривые — функции `t → t` для `interpolate(..., { easing: ease.glide })`. Одно и то же сглаживание на всём подряд делает ролик ватным. Резкие прилёты (`snap`) рядом с плавными переносами (`glide`) дают ритм.

## Вход и выход

- `rise(frame, { delay = 0, duration = 12, distance = 36, u = 1 })` → стиль `{ opacity, transform }` — проявление с подъёмом. По умолчанию для текста и карточек.
- `popIn(frame, { delay = 0, fps = 30, from = 0.4 })` → стиль `{ opacity, transform }` — выскакивает с пружиной из масштаба `from`. Иконки, наклейки, число.
- `maskRise(frame, { delay = 0, duration = 14 })` → стиль `{ clipPath, transform }` — строка выезжает из-под невидимого края; оберни в блок с `overflow: hidden`.
- `wordRise(text, frame, { delay = 0, every = 3, duration = 10, u = 1 })` → `[{ word, style }]` — слова по одному через `every` кадров. Только для короткой ключевой фразы.
- `slideIn(frame, { delay = 0, duration = 14, from = "left", distance = 120, u = 1 })` → стиль `{ opacity, transform }` — въезд с `left`, `right`, `top` или `bottom`.
- `exit(frame, length, { duration = 7, distance = 18, u = 1 })` → стиль `{ opacity, transform }` — уход в последние `duration` кадров элемента длиной `length` (`durationInFrames`). Перемножь `opacity` со входом.

## Текст, который происходит

- `typeOn(text, frame, start, end)` → строка — набранная к кадру часть текста, с паузами на пробелах и знаках, как у живой руки.
- `caretOn(frame, typing, fps = 30)` → `boolean` — видна ли каретка: горит во время набора, мигает после.
- `countUp(frame, from, to, start, end, { decimals = 0 })` → число — набегает до значения.
- `sweep(frame, start, duration = 10)` → 0–1 — маркер проходит по слову: `transform: scaleX(...)`, `transformOrigin: "left"`.

## Контакт: одно вызывает другое

- `press(frame, at, { depth = 0.08, fps = 30 })` → масштаб — кнопка проседает в кадре `at` и возвращается.
- `cursorPath(frame, [{ x, y, at, click }])` → `{ x, y, press }` — курсор едет по точкам (`at` — кадр прибытия) и кликает там, где `click: true`. Отдай в `<Cursor>` и в `press` кнопки, по которой кликнули: зритель должен видеть причину.
- `shake(frame, at, { amplitude = 14, duration = 12, u = 1 })` → px по горизонтали — короткая затухающая тряска: ошибка, отказ.
- `squash(frame, at, { amount = 0.18, fps = 30 })` → `{ scaleX, scaleY }` — предмет приземлился (`transformOrigin` — низ).
- `gather(frame, i, n, start, { duration = 18, spread = 260, u = 1 })` → стиль `{ opacity, transform }` — `i`-й из `n` элементов слетается на своё место: сборка списка, набор из частей.
- `along(points, t)` → `{ x, y }` — точка на ломаной `[{ x, y }]` при доле пути `t` 0–1: путь предмета.

## Перенос: следующая сцена вырастает из этой

Это то, что отличает моушен от слайдов. На каждой границе сцен решай, что её переживает.

- `morph(frame, from, to, start, end, curve = ease.glide)` → `Rect` — контейнер меняет размер и место: кнопка становится окном, карточка — экраном. `Rect` — `{ x, y, w, h, r }` в пикселях кадра (`r` — скругление). `rectStyle(rect)` → CSS с `position: absolute`. Содержимое следующей сцены рисуй внутри него.
- `zoomThrough(frame, target, { width, height }, start, end, curve = ease.whip)` → стиль `{ transform, transformOrigin }` — камера влетает в деталь (`target` — её `Rect` в кадре), пока та не заполнит экран. Примени стиль к сцене целиком, а следующую сцену начни как эту деталь во весь экран.
- `iris(frame, x, y, { width, height }, start, end, { reverse = false })` → стиль `{ clipPath }` — следующая сцена раскрывается кругом из точки `(x, y)`; `reverse` — сворачивается в неё.
- Тот же предмет меняет состояние: окно чата остаётся, меняется ответ; сумма остаётся, вокруг появляется список. Это самый частый и самый сильный перенос — держи сквозной образ в одном компоненте через несколько сцен.

Стык без переноса допустим, если между сценами снова автор в кадре, или это намеренная серия коротких ударов.

## Камера

- `camera(frame, keys, { width, height })` → стиль `{ transform, transformOrigin }` — камера по ключам `CameraKey` `{ at, x, y, scale, ease }` над «сценой» размером с кадр: `(x, y)` — точка сцены в центре кадра, `ease` — кривая подхода к ключу (по умолчанию `ease.glide`). Чтобы следовать за предметом, ставь ключ на пару кадров раньше него с `ease.glide`; для рывка — ключ в точке приземления с `ease.whip`. Примени стиль к контейнеру сцены.
- `drift(frame, { amplitude = 4, period = 90, u = 1 })` → `{ x, y }` px — едва заметное «дыхание» камеры в долгом удержании, не больше 4–6 px. В паузах лучше без него.

## Ритм

- Длины сцен и движений разные: удар 0,3 с рядом с удержанием 2,5 с.
- Пауза, где ничего не движется, нужна, чтобы акцент был заметен.
- `stagger(count, span, { min = 3, max = 18 })` → кадров между элементами, чтобы `count` штук уложились в `span` кадров.
- Вход 0,3–0,5 с, выход 0,2–0,3 с, между ними — время прочитать (`readingSeconds`).
