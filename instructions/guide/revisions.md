# Правки автора и перемонтаж

Открывай, если в `request.json` есть `comments` или `previousVersion`.

## Перемонтаж

Если в `request.json` есть `previousVersion`, её `decisions.json`, `overrides.json`, `graphics.json` и `custom/` уже лежат в текущей папке, вместе с `clips/` и `images/`. Пакет вкуса берётся текущий: если автор сменил пакет, сохрани содержание графики и переоформи её под новый пакет. Меняй только то, о чём просят новые `comments`. Остальное должно остаться как в прошлой версии, иначе автору придётся заново проверять весь ролик.

## Правки с таймкодом

Автор оставляет правку, остановив видео на нужном моменте. У такой правки есть поле `at`:

```json
{ "body": "тут кашель", "at": { "version": "v001", "programSeconds": 3.2, "sourceSeconds": 12.7, "words": "Попросил поменять цвет кнопки" } }
```

- `programSeconds` — время в смонтированной версии, которую смотрел автор.
- `sourceSeconds` — то же место в исходнике; именно с этим временем ты работаешь.
- `words` — что звучит рядом, чтобы найти единицу в `transcript.md`.

Правка относится к месту рядом с этой секундой, а не к точной границе: найди ближайшую единицу или звук и решай по смыслу. В `reply.md` отвечай на такую правку с её таймкодом.

## Правки к отрезку

Автор может выделить отрезок на таймлайне. Тогда в `at` есть и конец:

```json
{ "body": "здесь покажи скриншот", "at": { "version": "v002", "programSeconds": 12.4, "sourceSeconds": 31.0, "programEndSeconds": 18.9, "sourceEndSeconds": 40.2, "sourceRanges": [{ "start": 31.0, "end": 34.6 }, { "start": 37.3, "end": 40.2 }], "words": "…все слова отрезка…" } }
```

- Правка относится ко всему отрезку: от `programSeconds` до `programEndSeconds` в версии автора.
- `sourceRanges` — куски исходника, которые попали в этот отрезок. Между ними вырезанное: не возвращай его, если автор об этом не просит.
- Элемент графики, который автор просит показать «здесь», ставь от начала первого куска до конца последнего: он должен идти весь выделенный отрезок. Границы отрезка автор ставит руками, сдвинь их до ближайшей паузы или границы фразы, если так чище.
- `words` — всё, что звучит в отрезке.

## Файлы в правке

К правке автор может прикрепить файлы — картинку, видео, звук:

```json
{ "body": "вставь это видео сюда", "at": { "programSeconds": 8.0, "sourceSeconds": 20.5, "words": "…" }, "files": ["assets/demo.mp4"] }
```

- Файлы лежат в материалах ролика (`assets/…`) и есть в `media.md`. Ставь их элементами `image` и `video`, звук — в `audio`, как любые материалы.
- Если у правки есть `at`, файл нужен именно там: в этой секунде или на весь отрезок. Если места нет, найди его по тексту правки и брифу.
- Если файл не подходит (не тот формат, слишком мал, закрывает лицо), скажи об этом в `reply.md` и предложи, как быть.
