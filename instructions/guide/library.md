# Готовые сцены

Готовые сцены и пометки лежат в модуле `cutroom`. В отличие от частей интерфейса, у каждой своя хореография: ты задаёшь данные и кадр начала. Цвета и шрифты берутся из стиля, вертикальный кадр поддерживается. Если сцена говорит то же, что автор, бери её, а не рисуй такую же с нуля. Сцена стоит внутри твоего компонента: ты решаешь, где она в кадре, что вокруг и как она переходит в следующую.

```tsx
import { ShareDonut } from "cutroom"
// внутри своего компонента, сцена на весь кадр:
<AbsoluteFill style={{ background: theme.background }}>
  <div style={{ position: "absolute", left: safe.left, right: safe.right, top: safe.top, bottom: safe.bottom, display: "flex", flexDirection: "column", alignItems: "center", justifyContent: "center", gap: 48 * u }}>
    <ShareDonut at={6} segments={[{ label: "Белки", value: 30 }, { label: "Жиры", value: 25 }, { label: "Углеводы", value: 45 }]} highlight={0} />
  </div>
</AbsoluteFill>
```

Общее у всех:

- `at` — кадр элемента, с которого сцена начинает двигаться (по умолчанию 0). Кадры в описаниях ниже считаются от `at`.
- Размеры (`size`, `width`, `height`, шрифт) — в пикселях при 1080. Ширина не больше безопасной зоны: обычно 860–940.
- Сцена занимает свой блок, и её можно ставить во flex или абсолютом. Исключения — `InkArrow` и `Confetti` (закрывают весь кадр, ставь их последними, на верхний уровень сцены) и `ComicPanels` (весь кадр с собственным фоном).
- Числа выводятся по-русски, с пробелом в тысячах (`formatNumber(value, decimals)`). Текст на экране перечисли в `text` сцены.
- Подписи давай короткими: одно-три слова. Длинную фразу отдай голосу и субтитрам.

## Цифры

- `ShareDonut({ segments, highlight = 0, unit = "%", size = 900 })` — кольцо долей. Доли рисуются по очереди (до шести), выделенная отделяется, её число появляется в центре. Около 2,5 с. Подходит для БЖУ в тарелке, бюджета, «каждый третий».
- `ActivityRings({ rings, size = 640 })` — до трёх колец целей: кольцо замыкается, а если цель перевыполнена, идёт на второй круг. Под кольцами считаются цифры. `rings` — `{ label, value, goal, unit }[]`. Подходит для шагов, воды, белка, минут.
- `BarChart({ bars, highlight = -1, unit = "", width = 900, height = 720 })` — столбцы каскадом вырастают из базовой линии, значения над ними. `bars` — `{ label, value }[]`, до 6.
- `LineChart({ values, labels = [], unit = "", width = 900, height = 640, draw = 40 })` — линия рисуется слева направо за `draw` кадров, последнее значение появляется в плашке. Подходит для веса, дохода, прогресса по неделям.
- `SlopeChart({ lines, highlight = 0, beforeLabel = "Было", afterLabel = "Стало", unit = "" })` — две стойки: «было» и «стало», линии тянутся через них, выделенная идёт в акценте. `lines` — `{ label, before, after }[]`, до 4.
- `UnitGrid({ total = 100, highlighted, columns = 10, caption })` — сетка точек, `highlighted` из них загораются по одной, над сеткой «N из M». Подходит для статистики понятным языком.
- `Fraction({ parts = 8, filled = 1, headline, caption })` — ряд ячеек, `filled` из `parts` заливаются. Сверху `headline` (по умолчанию «1/8»).
- `StackedBar({ segments, highlight = -1, unit = "", total })` — одна полоса делится на части, части растут по очереди, под ними подписи. Подходит для суток, бюджета, тарелки.
- `Waterfall({ start, steps, totalLabel = "Итого", unit = "" })` — водопад: от начального значения через плюсы и минусы к итогу. `start` — `{ label, value }`, `steps` — `{ label, value }[]` со знаком. Подходит для калорий за день, денег за месяц.
- `Radar({ axes, values, compare, valueLabel, compareLabel, max = 1, size = 760 })` — паутинка: сетка, пунктир сравнения, поверх неё основной профиль. От 3 до 7 осей. Подходит для состава продукта, навыков, характеристик.
- `Tally({ count, caption, every = 2 })` — палочки от руки пачками по пять, затем крупное число. Подходит для дней без сахара, подходов, попыток.
- `Stats({ stats, every = 10 })` — две-четыре крупные цифры одна под другой, каждая считается. `stats` — `{ value, label, prefix, suffix, decimals }[]`.

## Время

- `ShotClock({ from = 24, tenthsBelow = 5, tick = 2.6, tenth = 1, title = "", subtitle = "", label = "", period = "", alarm, width = 900, hold = 6 })` — табло. Целые секунды тикают (`tick` кадров на секунду), последние `tenthsBelow` — десятыми в цвете `alarm` (по умолчанию акцент). На нуле вспышка; если задан `title`, табло уезжает вверх, а `title` влетает крупно. До нуля `14 + (from − tenthsBelow) · tick + tenthsBelow · 10 · tenth` кадров.
- `Countdown({ from = 3, every = 18, final, caption, size = 760 })` — крупная цифра в кольце, которое убывает; каждая цифра держится `every` кадров, после нуля появляется `final` («Старт!»).
- `ClockSweep({ from = 0, to = 15, label, caption, size = 680, sweep = 40 })` — стрелка циферблата проходит от `from` до `to` минут и закрашивает сектор, потом появляется `label` («15 минут»).
- `Calendar({ month, startsOn = 0, days = 30, marks = [], pick })` — месяц: дни появляются волной, у дней из `marks` (`{ day, label }[]`) появляются метки, день `pick` обводится акцентом. `startsOn` — день недели первого числа (0 — понедельник).

## Сравнение и состав

- `BeforeAfter({ before, after, beforeNode, afterNode, beforeLabel = "До", afterLabel = "После", title, width = 860, aspect = 4/5, fit = "cover", pauseAt = 0.5, hold = 54 })` — шторка на картинке. Рамка появляется, шторка уходит к середине, держится `hold` кадров и открывает «после». Если дан только `after`, «до» станет той же картинкой без цвета. Около 3 с.
- `SplitScreen({ top, bottom, topLabel, bottomLabel, width = 940, height = 1300 })` — две картинки одна над другой: верхняя серая, «как обычно», нижняя яркая, «как надо».
- `Versus({ leftLabel, rightLabel, rows, versus = "vs" })` — две карточки: серая с зачёркнутыми цифрами «как было», под ней в акценте победитель. `rows` — `{ label, left, right }[]`, до 4. Подходит для сравнения подходов, диет, продуктов.
- `BalanceBeam({ light, heavy, caption })` — качели: на одну сторону падает куча лёгкого (`light`, строки), на другую — одно тяжёлое `heavy`, и качели перевешивают. Подходит для «одна привычка весит больше десяти советов».
- `ExplodedView({ labels, notes = [], highlight = 0, width = 940, closeAt })` — изометрические плиты расходятся, к каждой выноска с номером, подписью и строкой `notes`. От 2 до 6 слоёв, сверху вниз. С `closeAt` плиты снова сходятся. Подходит для показа, из чего что-то состоит.
- `Flows({ sources, target, unit = "" })` — потоки из нескольких источников (`{ label, value }[]`) вливаются в один блок, его сумма считается. Подходит для вопросов вида «откуда сахар», «из чего доход».
- `Venn({ sets, center, caption, size = 900 })` — два круга съезжаются, их пересечение заливается акцентом, в нём появляется `center`. `sets` — две подписи.

## Текст

- `StrikeReplace({ from, to, size = 88, strike = 14, hold = 12, swap = 10 })` — старые слова зачёркиваются, на их месте появляются новые. Обе фразы в одну строку. Подходит для «миф → факт», «ошибка → как правильно».
- `HookPunch({ lead, payoff, size = 84, beat = 12 })` — хук в два-три удара: строки `lead` влетают по очереди и гаснут, крупно приземляется `payoff` в акценте. Подходит для первых секунд ролика.
- `Pov({ setup, punchline, label = "POV:" })` — плашка «POV:», ситуация по словам, затем панчлайн курсивом в акценте.
- `Quote({ quote, highlight, author, role, size = 66 })` — цитата: кавычка падает, слова поднимаются, фраза `highlight` выделяется маркером, внизу подпись. Подходит для отзыва клиента или цитаты исследования.
- `Steps({ steps, notes = [], eyebrow, every = 14 })` — пронумерованные шаги сверху вниз, линия дорисовывается от шага к шагу. От 2 до 5 шагов.
- `Acronym({ words, eyebrow, caption, expandAt = 24 })` — аббревиатура стоит крупно, потом каждая буква уезжает началом своего слова. `words` — слова по буквам: `["Белки", "Жиры", "Углеводы"]`.

## Пометки

Оборачивают своё содержимое и встают прямо в строку текста или поверх картинки.

- `Marker({ children, color, textColor })` — маркер с пружиной прокрашивает слова.
- `InkUnderline({ children, strokeWidth = 14, steps = 5, seed })` — подчёркивание кистью в несколько покадровых поз.
- `ScribbleCircle({ children, width, height, strokeWidth = 14, steps = 10, laps = 1.15, seed })` — кисть обводит область `width × height`: слово, число или часть картинки (тогда ставь абсолютом).
- `InkArrow({ from, to, curvature = 0.3, color, strokeWidth = 16, headSize = 46, draw = 18, seed })` — рисованная стрелка от `from` к `to`, точки `{ x, y }` в пикселях кадра. Знак `curvature` гнёт её в другую сторону, `seed` меняет дрожь руки.
- `Handwrite({ text, size = 72, color, perStep = 1.6, align = "center" })` — текст пишется от руки, по букве, с наклоном и неровной строкой; кириллица есть. `handwriteFrames(text)` — сколько кадров он займёт. `HAND_FONT` — тот же рукописный шрифт для своего CSS.
- `CheckList({ items, size = 88, markColor })` — рукописный список пишет себя, потом пункты с `done: true` по одному отмечаются и зачёркиваются. `items` — `{ text, done }[]`.

## Фото и видео

Картинки передаются элементу через `props.files` (см. ниже) или своей отрисовкой: в параметр картинки можно передать адрес или JSX.

- `GridMontage({ pictures, width = 900, aspect = 4/5, beat = 14 })` — сначала одна картинка, потом сетка 2×2, затем 3×3, смена на каждые два `beat`.
- `Polaroid({ picture, caption, width = 620, tilt = -4 })` — полароид падает на стол, снимок проявляется, подпись пишется от руки.
- `UpClose({ picture, focus = { x, y }, zoom = 2.6, caption, pushAt = 14 })` — камера наезжает на деталь (`focus` в долях картинки), кольцо отмечает её, затем подпись. Подходит для состава на этикетке, детали техники.
- `Tour({ picture, stops, aspect = 3/4, width = 940, every = 36 })` — камера идёт по картинке от остановки к остановке, остальное затемняется, на остановке появляется подпись. `stops` — `{ x, y, w, h, label }[]` в долях картинки. Подходит для разбора документа, меню, анализа, скриншота.

## Камера и эффекты

- `Impact({ children, intensity = 1 })` — содержимое падает сверху с ударом и сплющиванием, кадр трясёт, в стороны летит пыль. Подходит для ключевой цифры или вывода.
- `Turntable({ front, back, width = 620, height = 820, spin = 60 })` — карточка поворачивается в 3D и показывает обратную сторону `back`. Подходит для «лицо и изнанка», этикетки и состава.
- `Confetti({ x = 0.5, y = 0.5, count = 140, lifetime = 90, colors, seed })` — залп конфетти из точки (`x`, `y` в долях кадра), при каждом рендере одинаковый.
- `Crumple({ children, direction = "right", ball = 220 })` — содержимое сминается в бумажный шарик, и тот улетает по дуге. Подходит для «выбросьте это»: вредный совет, плохой продукт.
- `ComicPanels({ panels, word = "БАМ!", burstAt = 40 })` — кадр раскалывается на три панели комикса, третья разрастается на весь кадр, влетает звезда со словом. `panels` — три JSX.
- `Blueprint({ children, width = 760, height = 760, labels = [], dimensions, wipeAt = 14 })` — содержимое шторкой превращается в чертёж: синяя сетка, белые линии, размеры `dimensions` (`{ width, height }` строками), точки с подписями `labels` (`{ x, y, text }`, координаты в долях).

## Сцены с интерфейсом

- `Booking({ host, event, day, slots, pick = 0, button = "Записаться", booked = "Вы записаны" })` — карточка записи: курсор выбирает время `slots[pick]`, нажимает кнопку, карточка превращается в подтверждение. Подходит для записи на консультацию или тренировку.
- `Streak({ title = "Урок пройден", streak, done, days, stats = [], cta = "Продолжить" })` — «урок пройден»: значок, цифры `stats` (`{ label, value }[]`), серия дней заполняется до `done`, счётчик серии растёт до `streak`.

## Переходы

- `Transition({ kind, from, to, start, end, direction = "left", blur = 16, seed })` — стык двух сцен одного компонента на весь кадр. До `start` показывается только `from`, после `end` — только `to`. Под сценами стоит фон стиля. Виды и длины:
  - `whip` — резкий пролёт с размытием, 10–14 кадров;
  - `zoomBlur` — удар внутрь кадра, 12–18;
  - `focusPull` — перевод фокуса, 12–18;
  - `pushThrough` — старая сцена пролетает мимо камеры, 16–22;
  - `pageTurn` — улетает страницей блокнота, 14–20;
  - `paperTear` — кадр рвётся, половины расходятся, 24–36;
  - `lightLeak` — засветка плёнки, 18–30.

  Это смена темы, а не перенос предмета: между этапами одного образа нужен перенос из `guide/motion.md`.
- `whipPan(frame, start, end, { direction, blur, u })` → `{ out, in }` — тот же пролёт, но голыми стилями для своих контейнеров.

## Картинки в своём компоненте

Сгенерированную картинку или фото автора в компонент передают через `props.files` элемента: `"files": { "photo": "images/plate.png" }`. Подходят ссылки `images/…`, `assets/…`, `library/other/…`. В компоненте `props.files.photo` уже будет адресом для `Img` и для сцен выше.

Сцены сделаны по мотивам remocn и частично перенесены из него по лицензии MIT. Рукописный шрифт — Caveat, лицензия OFL.
