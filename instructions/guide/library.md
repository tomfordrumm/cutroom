# Готовые сцены

Готовые сцены и пометки в модуле `cutroom`. Это не части интерфейса: у каждой своя хореография, ты задаёшь данные и кадр начала. Цвета и шрифты берутся из стиля, размеры указаны в пикселях при 1080, вертикальный кадр поддерживается. Бери готовую сцену, когда она говорит то же, что автор, и не рисуй такую же с нуля. Сцена стоит внутри твоего компонента: ты решаешь, где она в кадре, что вокруг и как она переходит в следующую.

```tsx
import { ShareDonut } from "cutroom"
// внутри своего компонента, сцена на весь кадр:
<AbsoluteFill style={{ background: theme.background }}>
  <div style={{ position: "absolute", left: safe.left, right: safe.right, top: safe.top, bottom: safe.bottom, display: "flex", flexDirection: "column", alignItems: "center", justifyContent: "center", gap: 48 * u }}>
    <ShareDonut at={6} segments={[{ label: "Белки", value: 30 }, { label: "Жиры", value: 25 }, { label: "Углеводы", value: 45 }]} highlight={0} />
  </div>
</AbsoluteFill>
```

Общее у всех:

- `at` — кадр элемента, с которого сцена начинает двигаться (по умолчанию 0). `speed` — множитель скорости.
- Размеры указаны в пикселях при 1080: `size`, `width`, шрифт. Ширина сцены не должна превышать безопасную зону: обычно 860–940.
- Сцена занимает свой блок, и его можно ставить во flex или абсолютом. Исключение — `InkArrow`: она закрывает весь кадр, поэтому ставь её последней, на верхний уровень сцены.
- Текст на экране, как и у своего компонента, перечисли в `text` сцены.

## Цифры

- `ShareDonut({ segments, highlight = 0, unit = "%", size = 900, at, drawLength = 52 })` — кольцо долей. Сначала по очереди рисуются доли (до шести), потом выделенная `highlight` отделяется, остальные гаснут, а её число появляется в центре. `segments` — `{ label, value }[]`, значения считаются долями от суммы. Подходит для доли в тарелке, бюджете или рынке, «каждый третий». Полный цикл занимает около 2,5 с.
- `ShotClock({ from = 24, tenthsBelow = 5, tick = 2.6, tenth = 1, title = "", subtitle = "", label = "", period = "", alarm, width = 900, at, hold = 6 })` — табло обратного отсчёта. Целые секунды тикают (`tick` кадров на секунду), последние `tenthsBelow` идут десятыми в цвете тревоги `alarm` (по умолчанию акцент). На нуле вспышка; если задан `title`, табло уезжает вверх, а `title` влетает крупно, под ним `subtitle`. Подходит для интервала, «за 30 секунд», дедлайна. Длительность: `14 + (from − tenthsBelow) · tick + tenthsBelow · 10 · tenth` кадров до нуля.

## Сравнение и состав

- `BeforeAfter({ before, after, beforeNode, afterNode, beforeLabel = "До", afterLabel = "После", title, width = 860, aspect = 4/5, fit = "cover", pauseAt = 0.5, hold = 54, at })` — шторка на картинке. Рамка появляется, шторка уходит к середине, держится `hold` кадров и открывает «после» целиком. Картинки передаются через `props.files` элемента (см. ниже). Если дан только `after`, «до» станет той же картинкой без цвета. Вместо картинок можно передать свою отрисовку в `beforeNode`/`afterNode`. Подходит для фото до и после, двух вариантов кадра, старого и нового интерфейса. Около 3 с.
- `ExplodedView({ labels, notes = [], highlight = 0, width = 940, at, closeAt })` — разбор на слои. Изометрические плиты расходятся, к каждой тянется выноска с номером, подписью `labels[i]` (сверху вниз, от двух до шести) и строкой `notes[i]` под ней. Плита `highlight` окрашена акцентом (`-1` — ни одна). С `closeAt` (кадр от `at`) плиты снова сходятся со щелчком. Подходит для показа, из чего что-то состоит: блюда, продукта, системы, тренировки. Раскрывается за 1 с.

## Текст и пометки

- `StrikeReplace({ from, to, size = 88, at, strike = 14, hold = 12, swap = 10, color, lineColor })` — старые слова зачёркивает линия акцента, затем на их месте появляются новые. Обе фразы в одну строку, до 4–5 слов. Подходит для пар «миф → факт», «ошибка → как правильно», «было → стало» словами.
- `InkArrow({ from, to, curvature = 0.3, color, strokeWidth = 16, headSize = 46, at, draw = 18, grain = 1, seed })` — стрелка, нарисованная кистью в покадровых позах; голова прорисовывается последней. `from`, `to` — точки `{ x, y }` в пикселях кадра (`width`, `height` компонента): от свободного места к предмету. `curvature` с другим знаком гнёт стрелку в другую сторону, другой `seed` даёт другую дрожь руки. Подходит для «смотрите сюда» на документе, этикетке, скриншоте или фото.

## Переход

- `whipPan(frame, start, end, { direction = "left", blur = 24, u })` → `{ out, in }` — резкий пролёт: обе сцены проносятся через кадр с размытием движения. Между `start` и `end` рисуй обе сцены: на уходящую надень стиль `out`, на приходящую — `in`. После `end` остаётся только новая. Длина 10–14 кадров. Это не перенос предмета: ставь его там, где автор сам резко меняет тему, а не между двумя этапами одного образа.

## Картинки в своём компоненте

Сгенерированную картинку или фото автора в компонент передают через `props.files` элемента: `"files": { "photo": "images/plate.png" }`. Подходят ссылки `images/…`, `assets/…`, `library/other/…`. В компоненте `props.files.photo` уже будет адресом для `Img` и `BeforeAfter`.
